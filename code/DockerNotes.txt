To run the API in docker container,
run this from the Code directory eventmgmt\code
docker build -f CreateTicketApi/Dockerfile -t createticketapi .
and then 
docker run -p 8091:8080 createticketapi

Open http://localhost:8091/swagger

delete all containers
docker rm $(docker ps -a -q)

Had to use SkiSharp to get it to work in container on Linux and also had to add the package reference below
only for container.
    <PackageReference Include="SkiaSharp.NativeAssets.Linux.NoDependencies" Version="3.119.0" />
Also AWS SQSHelper needed the region specified since it cannot pick up default region from local C:\ configurationfile

Also neeed to change development json config file from localhost to host.docker.internal
