Anyway, to get it to run with ngrok,
start one tunnel for vite and one for api.

ngrok http 5220 ---for the api
Use the url generated in VITE_API_BASE_URL in .env.local

ngrok http 5173 -- for vite
Use the url generated here to add to Program.cs in api server for the cors policy.
Also had to change vite.config.ts file. 
Turned off https option here as well,
, addded allowed hosts for ngrok,
 and hosts:true as well.
